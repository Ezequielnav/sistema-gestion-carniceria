# Sistema de gestión - Carnicería Rojano

Trabajo de Campo (Ingeniería Informática). Proyecto individual, mantenido por una sola persona: preferir soluciones simples.

## Fuente de verdad
- La documentación está en /docs (Markdown). Leer los archivos relevantes antes de programar.
- Requisitos: RF-xx y RNF-xx. Casos de uso: CU-xx. No inventar reglas del negocio: si falta un dato, preguntar o dejarlo como pendiente en docs/01-relevamiento.md.
- Diagramas en Mermaid dentro de /docs/diagramas.

## Reglas de trabajo
- Trabajar siempre en una rama nueva. Nunca commitear ni pushear a main (protegida, solo vía Pull Request).
- Todo cambio de código incluye tests y actualiza la documentación afectada en /docs.
- No acceder a credenciales, claves ni archivos .env. No usar datos reales del negocio: solo datos de ejemplo.
- No ejecutar comandos destructivos ni instalar dependencias sin explicarlo antes.
